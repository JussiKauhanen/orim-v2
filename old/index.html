Ask the AI
Type what you want and Claude builds on the board as it answers, one undo step per request. Select notes and let it group, summarise, translate or turn them into tickets.

        
Photo to board
Snap a whiteboard, sticky notes or a screenshot of a diagram, and Claude rebuilds it as shapes, frames and lines you can edit.

        
Styles and templates
Journey maps, layered architecture, mind maps, SWOT and sprint plans, in Midnight, Pastel, Blueprint or Sketch styles, with fonts to match.

        
Write or draw
Type Mermaid or plain lines like App -> Dataverse, or drag things around. Both stay in sync, and export to PNG, SVG, draw.io or Markdown.

        
Screens, docs and tickets
Phone, iPad and desktop mockups, comparison tables, documents, and tickets that copy into Azure DevOps or export as its import CSV.

        
Real cloud icons
679 Azure, Power Platform and Dynamics 365 icons, picked for you from service names.

Mermaid syntax

    
flowchart LR
  app@{ icon: "pp:power-apps", label: "Field app" }
  fn@{ icon: "azure:function-apps", label: "API" }
  db[(Orders)]
  ok{Valid?}
  subgraph cloud [Azure]
    fn
  end
  app -->|calls| fn
  fn -.-> db
  fn ==> ok
  style ok fill:#fff3b0,stroke:#d4ac0d

    
Icon packs: azure:, pp: (Power Platform) and d365: (Dynamics 365). Hover a library icon to see its id. Other Mermaid renderers show icon nodes only when the same icon pack is registered there.

    
Canvas positions are saved as %% @pos comment lines, which Mermaid ignores. Turn on Canvas data above the code to see them.
